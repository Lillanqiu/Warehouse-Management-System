# 学校资产管理系统查漏补缺计划

## 当前项目结构

- 前端：原生 HTML/CSS/JavaScript，核心文件为 `index.html`、`styles.css`、`app.js`。
- 后端：Python 标准库 HTTP 服务，核心文件为 `server.py`。
- 数据库：SQLite，随 Docker 容器挂载持久化。
- 部署：Docker Compose，默认访问 `http://127.0.0.1:38280/`。

## 已有能力

- 用户登录、普通用户和管理员权限。
- 用户管理、部门开关、修改密码、管理员申请。
- 资产台账、资产分类、资产新增/编辑/删除。
- 出入库登记、批量导入、Word/Excel 导入留档。
- 普通用户资产申请、采购需求清单。
- 耗材库存管理雏形：当前库存、安全库存、库存预警、入库/出库流水、库存调整。
- 操作日志、导入电子档留档、打印模板设置。

## 主要缺口

- 角色权限还不完整：缺少资产管理员、部门负责人、普通教师的细分 RBAC。
- 位置管理需要学校场景化：校区、楼栋、楼层、房间、实验室、仓库。
- 资产分类目前是单层，需要升级为多级分类和分类编码。
- 资产台账字段还不够完整：品牌、单位、单价、购置日期、供应商、资产来源等需要补齐。
- 二维码标签尚未实现。
- 盘点任务和盘点差异报告尚未实现。
- 调拨、维修、报废目前缺少正式单据模型。
- 报表统计还需要独立页面和筛选条件。
- 库存流水目前复用出入库记录，后续应补独立 `stock_records` 表。

## 开发优先级

1. 基础数据补齐：位置管理、分类编码、多级分类、角色入口。
2. 资产核心补齐：资产详情、二维码标签、台账字段、编号规则。
3. 流转能力补齐：领用、借用、归还、调拨的独立单据和流转日志。
4. 盘点与报表：盘点任务、扫码/编号盘点、差异报告、资产统计。
5. 扩展流程：维修、报废、审批流、导入导出增强。

## 当前已开始补齐

- 新增位置管理数据表和基础数据页面。
- 资产新增/编辑时，存放位置改为从位置清单中选择。
- 位置名称编辑后会同步更新资产台账。
- 删除位置前会校验是否仍有资产使用。
- 资产分类开始支持父级分类、分类编码和分类类型。
- 自动资产编号开始支持 `学校代码-分类编码-年份-流水号` 规则。
- 资产列表增加详情入口，可查看责任人、位置、状态和流转记录。
- 二维码/扫码查看资产放入设置页的“实验室功能”，作为后续扫码盘点入口。
- 新增盘点管理入口，支持按全部、位置、分类、责任人、状态生成盘点任务。
- 盘点明细支持录入实际位置、状态、责任人，并自动生成差异类型。
